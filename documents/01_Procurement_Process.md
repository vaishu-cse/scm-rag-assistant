# L&T Supply Chain Management

## Procurement Process Guide

### Purpose

The procurement process ensures that materials required for construction projects are purchased efficiently while maintaining quality, cost control, and compliance.

## Procurement Workflow

1. Material Requirement Raised
2. Purchase Requisition Approval
3. Vendor Selection
4. Request for Quotation (RFQ)
5. Technical Evaluation
6. Commercial Evaluation
7. Purchase Order Creation
8. Material Delivery
9. Goods Receipt
10. Invoice Verification
11. Payment Release

## Purchase Requisition (PR)

A Purchase Requisition is an internal request created by a project engineer requesting required materials.

### Required Information

| Field | Example |
|--------|----------|
| Project Code | LT-PJ-2026-001 |
| Material | Cement OPC 53 Grade |
| Quantity | 500 Bags |
| Required Date | 15 Sept 2026 |
| Cost Center | Civil Works |

## Approval Levels

| Amount | Approver |
|----------|------------|
| Up to ₹50,000 | Site Engineer |
| ₹50,001–₹5,00,000 | Project Manager |
| Above ₹5,00,000 | Procurement Head |

## Frequently Asked Questions

### How is a vendor selected?

Vendors are evaluated based on quality certification, pricing, delivery performance, and previous project experience.

### What happens after PR approval?

An RFQ is sent to approved vendors before creating a Purchase Order.
