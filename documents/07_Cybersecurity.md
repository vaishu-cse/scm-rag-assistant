# Cybersecurity Basics

## Overview

Cybersecurity is the practice of protecting computers, networks, applications, and digital information from unauthorized access, misuse, disruption, or destruction.

Cybersecurity focuses on protecting three fundamental properties of information:

- Confidentiality
- Integrity
- Availability

These three principles are commonly known as the CIA triad.

## Confidentiality

Confidentiality ensures that information can only be accessed by authorized individuals or systems.

Examples include:

- Password protection
- Encryption
- Access control
- Multi-factor authentication

For example, a company's employee salary information should only be accessible to authorized personnel.

## Integrity

Integrity ensures that information remains accurate and has not been modified without authorization.

Examples include:

- File integrity monitoring
- Digital signatures
- Hash verification
- Database access controls

If a file is modified by an unauthorized person, its integrity may have been compromised.

## Availability

Availability ensures that authorized users can access systems and information when they need them.

Examples include:

- Backup systems
- Disaster recovery
- Redundant servers
- Load balancing
- Monitoring systems

A website becoming unavailable because of a server failure is an example of an availability problem.

## Authentication

Authentication verifies the identity of a user or system.

Common authentication methods include:

- Username and password
- Multi-factor authentication
- Biometric authentication
- Security tokens
- Digital certificates

Multi-factor authentication requires users to provide more than one form of verification.

## Authorization

Authorization determines what an authenticated user is allowed to access or perform.

For example:

A user may be authenticated successfully but still be unauthorized to access an administrator dashboard.

## Encryption

Encryption converts readable information into an encoded format that cannot be easily understood without the appropriate key.

Two common categories are:

### Symmetric Encryption

The same key is used for encryption and decryption.

### Asymmetric Encryption

Different keys are used for encryption and decryption.

A common example is public-key cryptography, which uses a public key and a private key.

## Common Cybersecurity Threats

### Phishing

Phishing attempts to trick users into revealing sensitive information through fraudulent emails, messages, or websites.

### Malware

Malware is malicious software designed to damage systems, steal information, or gain unauthorized access.

Examples include:

- Viruses
- Worms
- Trojans
- Ransomware
- Spyware

### Ransomware

Ransomware is malicious software that prevents access to data or systems and typically demands payment from the victim.

### Denial-of-Service Attacks

A denial-of-service attack attempts to make a service unavailable by overwhelming it with requests or other malicious traffic.

## Security Best Practices

Organizations and individuals can improve security by:

- Using strong and unique passwords
- Enabling multi-factor authentication
- Keeping software updated
- Regularly backing up important data
- Avoiding suspicious links and attachments
- Limiting user privileges
- Monitoring unusual system activity

## Incident Response

Incident response is the process of handling cybersecurity incidents.

A typical incident response process includes:

1. Preparation
2. Detection
3. Analysis
4. Containment
5. Eradication
6. Recovery
7. Lessons learned

## Example

Suppose an employee receives an email containing a suspicious link.

The employee should avoid opening the link and report the message to the security team.

The security team can investigate the email, determine whether it is malicious, block related indicators, and check whether other users received the same message.

## Summary

Cybersecurity protects digital systems and information from unauthorized access, modification, disruption, and destruction.

The CIA triad—confidentiality, integrity, and availability—is a fundamental concept for understanding information security.
